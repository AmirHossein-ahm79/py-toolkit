# 🐍 Python Toolkit

مجموعه‌ای ساده و کاربردی از چند ابزار خط فرمان (CLI) که با Python ساخته شده است.  
هدف این پروژه، جمع‌آوری چند ابزار کوچک و قابل استفاده در یک برنامه‌ی واحد است.

## ✨ امکانات

این پروژه در حال حاضر شامل ابزارهای زیر است:

### 1. جستجو در فایل‌ها
با وارد کردن مسیر یک پوشه و یک کلمه، برنامه به‌صورت بازگشتی فایل‌های موجود در پوشه و زیرپوشه‌ها را بررسی می‌کند و محل پیدا شدن عبارت، شماره خط و تعداد تطابق‌ها را نمایش می‌دهد.

### 2. Caesar Cipher
ابزاری برای رمزگذاری و رمزگشایی متن با استفاده از **رمز سزار (Caesar Cipher)**.

امکانات:
- رمزگذاری متن
- رمزگشایی متن
- تعیین مقدار جابه‌جایی (Shift)
- پشتیبانی از حروف انگلیسی بزرگ و کوچک

> **توجه:** رمز سزار یک روش رمزنگاری امن و مناسب برای حفاظت از اطلاعات حساس نیست و در این پروژه بیشتر جنبه‌ی آموزشی دارد.

### 3. بررسی وضعیت وب‌سایت
با وارد کردن آدرس یک وب‌سایت، برنامه اطلاعاتی مانند موارد زیر را نمایش می‌دهد:

- آدرس نهایی پس از Redirect
- کد وضعیت HTTP
- زمان پاسخ
- وضعیت کلی وب‌سایت

### 4. قیمت ارز
این ابزار قیمت تعدادی از ارزها را دریافت و در ترمینال نمایش می‌دهد.

ارزهای پشتیبانی‌شده در نسخه فعلی:

- دلار
- یورو
- درهم
- پوند
- افغانی
- دینار عراق
- لیر ترکیه
- یوان چین
- ریال عمان

داده‌های قیمت ارز از صفحه‌ی مربوط به قیمت ارز سایت **Bitpin** دریافت می‌شوند.


## 🚀 نصب و اجرا

ابتدا مخزن را دریافت کنید:

```bash
git clone https://github.com/AmirHossein-ahm79/py-toolkit.git
cd py-toolkit
```

سپس وابستگی‌های پروژه را نصب کنید:

```bash
pip install -r requirements.txt
```

در نهایت برنامه را اجرا کنید:

```bash
python main.py
```
